# 腕の条件

同じ課題を、道具立てだけ変えて解かせる。**課題文も参照解も同一。**

| 腕 | 道具 | 禁止 |
|---|---|---|
| armB | 知識のみ。ファイルを読むだけ | シェル・コード実行。下請けエージェントは可（第1回で実際に使った） |
| armC | 知識＋コード実行。自分でパーサを書く | IFC 専用ライブラリ（ifcopenshell 等）。読むこと自体を測っているため |

armC に既製ライブラリを許すと「ライブラリがあるか」を測ることになり、
このベンチの問い（**規格文書から自力で読めるか**）と別物になる。
第1回の armC も自分でパーサを書いており、条件は揃っている。

両腕とも見てはいけないもの:

    reference/   参照解そのもの
    bench/       抽出器と採点器
    checker/     敵対テスト
    out/         採点結果
    README.md    答えと解説が書いてある
    arms/        この条件書（他方の腕の条件）
