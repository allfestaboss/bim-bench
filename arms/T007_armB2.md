# armB2 — armB の条件記述を正して測り直す（T007、完成形・{RUN} のみ差し込み）

**なぜ測り直すか。**

T007 の armB に渡した制約文は「ファイルは Read / Grep / Glob で読むこと。この3つは
使える」と書いていた。**この環境の下請けセッションに Grep と Glob は存在しない。**
別セッションで実測し、エラー文まで確認した。

    Error: No such tool available: Grep. Grep is not available in this session —
    search file contents with `grep` via the Bash tool instead.

armB の設計上の条件は「知識のみ。ファイルを読むだけ。**シェル・コード実行は禁止**」
なので、検索できないこと自体は設計どおりである。**壊れていたのは条件ではなく
プロンプトのほうで、存在しない道具を使えと指示していた。**

armB2 は、その1点だけを正した armB である。**測りたいのは「嘘がコストを歪めたか」。**
armB の実測は3走で統括 1,002,273 トークン（下請け分を除く）、armC は3走で 251,631。
嘘が原因で無駄が出ていたなら armB2 は下がるはずで、下がらなければ
armB の数字はそのまま使える。

**armB との差は2点だけである。**

  1. 道具の説明を実測どおりに直した（Read だけ。Grep / Glob は無い。Bash は禁止）
  2. 下請けの結果は通常の戻り値経路で返り、**遅いことがある**（T007 では最後の1体が
     起動から約23分後に届いた）と先に伝えた。T007 では運用側がこの遅さを
     「経路の故障」と誤診断して打ち切りを指示し、従った走行が 7/13 に落ちている。
     **その誤診断を繰り返さないための情報であって、課題の中身ではない。**

課題文・参照解・設問は T007 と一字一句同じ。`tasks/T007/task.json` も
`reference/T007.json` も触っていない。

## 出すもの

`attempts/T007/armB2_{RUN}.json` に、`answer_format` と同じ形の JSON を1つ書く。

    {"task": "T007", "answers": {"spatial_all": 0, ... }}

- 値は**17ファイル全体の合計**の整数1つ。ファイルごとの内訳は要らない
- **採点は完全一致のみ。**惜しい値に部分点は無い。1でもずれたらその設問は0点
- 分からない設問は**書かなくてよい**。未回答は0点だが、
  **当てずっぽうで埋めても期待値は上がらない**（完全一致のみなので）
- **JSON として壊れていたら失格**（0点）。書いたあと必ず読み直して構文を確認する
- **部分提出も受け付ける。時間や予算が尽きそうなら、そこまでの値を必ず正しい JSON で出すこと。**
  空提出は0点になる。途中でも書き出すほうが常に良い

## 制約

**コードを実行してはいけない。** シェル（Bash）、スクリプトの作成と実行、
Python / awk / sed などによる集計は全て禁止。

**このセッションで使える読み取りの道具は Read だけである。**（実測済み。
Grep と Glob はこの環境に存在せず、呼ぶと「Bash の grep を使え」と返るが、
その Bash は上のとおり禁止されている。）**探す手段は無い。読むしかない。**
これは armB の設計上の条件であって、不備ではない。

下請けエージェント（Task/Agent ツール）を立てるのは**可**。
ただし**下請けにも同じ制約が及ぶ。**下請けにコードを書かせて数えさせるのは違反である。

**下請けの結果は通常の戻り値経路で返る。ただし遅いことがある。**
同時実行に上限があり、体数が多いと波状に処理される。前回の走行では最後の1体が
起動から約23分後に届いた。**遅いことを故障と読み違えて打ち切らないこと。**
（前回、運用側がこれを誤診断して打ち切りを指示し、従った走行の点数が落ちた。）
なお下請けが結果を `SendMessage` で親へ返そうとすると失敗することがあるが、
**戻り値のほうは届く。**

`attempts/T007/` にある他の走行の答案と報告を見てはいけない（上記のとおり）。

作業用の一時ファイルが要る場合は
`/private/tmp/claude-501/-Users-boss-dev-01-projects/826e8fde-631a-4aed-a5c1-124ba794daae/scratchpad/T007_armB2_{RUN}/`
の下だけを使うこと。**他の走行と同じパスを使ってはいけない。**

制約を守れなかった場合は、報告に「どこで何を使ったか」を必ず書くこと。
**申告しても減点しない。**申告されない違反だけが測定を壊す。
